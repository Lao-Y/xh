## 使用

1. 将整个 `mingding-worldbook-backgrounds` 文件夹上传到 `Lao-Y/xh` 的 `main` 分支，保持文件名不变。
2. 在酒馆助手中导入 `命定之诗-Galgame-v5.7.0.json`，停用旧版同类 Galgame 脚本，避免双重运行。
3. 打开舞台顶栏「素材与规则」，导入 `命定之诗-背景规则.json`。这个 JSON 含 198 条背景规则，不含立绘规则。
4. 规则优先读取最新助手消息的 `<tp>日期时间 @ 地点 | 天气</tp>`；缺失时回退到 MVU 的 `世界.时间`／`世界.地点`。18:00–05:59 用夜景，06:00–17:59 用日景。时间不明确时优先使用日景。重点地点的每个时段有 3 张可随机选，其他地点按实际图片数选择，地点／时段不变时保持当前图。

规则 JSON 和脚本在本地离线测试通过，图片路径及尺寸已核对；**尚未在真实 SillyTavern 中验证**。图片上传 Git 后，才能验证远程加载。
